# Employee Metrics Integration Guide for Frontend Developers

This document provides a comprehensive guide for integrating the updated Employee endpoints into the frontend UI. The `GET /employees` endpoints have been enriched with calculated business metrics: **TUSHUM** (Income / Revenue), **REJA / FAKT** (Target vs. Actual KPI), and **MIJOZLAR** (Assigned Client Count).

---

## 📌 Summary of Endpoints Updated

The following endpoints now automatically include the new metric objects in their JSON responses:

* `GET /api/v1/employees` (Paginated list of employees)
* `GET /api/v1/employees/:id` (Single employee details)
* `GET /api/v1/employees/me` (Current logged-in user profile & employee details)

---

## 📐 Response Schema & Field Definitions

Each employee object returned by these endpoints includes 3 new top-level properties: `tushum`, `reja_fakt`, and `mijozlar_count`.

### 1. `tushum` (Income / Total Revenue)
Represents the overall revenue generated by the employee.

```json
"tushum": {
  "amount": 4400000,
  "currency": "RUB",
  "formatted": "4,400,000 ₽"
}
```

* **`amount`** (`number`): Raw numeric total revenue. Use for sorting, filtering, or client-side math.
* **`currency`** (`string`): Currency code (`"RUB"`, `"UZS"`, `"USD"`, `"EUR"`).
* **`formatted`** (`string`): Pre-formatted string with standard thousand separators and currency symbol. Ready for direct UI display.

---

### 2. `reja_fakt` (Target Plan vs. Actual Progress)
Represents the employee's KPI target, actual sales completed, achievement percentage, and completion status.

```json
"reja_fakt": {
  "plan_target": 3800000,
  "fact_amount": 4400000,
  "percentage": 115.79,
  "currency": "RUB",
  "status": "Bajarildi",
  "status_code": "COMPLETED",
  "formatted_plan": "3,800,000 ₽",
  "formatted_fact": "4,400,000 ₽"
}
```

* **`plan_target`** (`number`): The target sales goal for the period. If no target is set, defaults to `0`.
* **`fact_amount`** (`number`): The actual sales completed.
* **`percentage`** (`number`): Completion percentage computed as `(fact_amount / plan_target) * 100` rounded to 2 decimal places.
* **`currency`** (`string`): Currency code for the plan.
* **`status`** (`string`): Human-readable status string (`"Bajarildi"` if `percentage >= 100%`, otherwise `"Jarayonda"`).
* **`status_code`** (`string`): Machine-readable status enum (`"COMPLETED"` vs. `"IN_PROGRESS"`). Use this for conditional badge styling.
* **`formatted_plan`** (`string`): Pre-formatted target plan string (e.g. `"3,800,000 ₽"`).
* **`formatted_fact`** (`string`): Pre-formatted actual sales string (e.g. `"4,400,000 ₽"`).

---

### 3. `mijozlar_count` (Assigned Clients Count)
Represents the total count of active clients assigned to the employee.

```json
"mijozlar_count": 2
```

* **`mijozlar_count`** (`number`): Total count of active clients. Renders directly into the badge in the **MIJOZLAR** column.

---

## 🎨 UI Table Column Mapping

Here is how each table column on the Employees UI maps to the API response fields:

| UI Column Header | API Data Binding | UI Component / Rendering Note |
| :--- | :--- | :--- |
| **ISM** | `first_name`, `last_name`, `picture_url` | Avatar circle + Full Name + Job title subtitle (`user_role`). |
| **LAVOZIM** | `user_role` or `department_display_name` | Department / Position badge. |
| **HOLAT** | `user_status` | Status badge (`Active` / `Pending` / `Banned`). |
| **TUSHUM** | `tushum.formatted` | Bold primary text (e.g., `4,400,000 ₽`). |
| **REJA / FAKT** | `reja_fakt.formatted_plan`, `reja_fakt.percentage`, `reja_fakt.status` | Target value (`3,800,000 ₽`), percentage badge (`116%`), and status text (`Bajarildi` / `Jarayonda`). Progress bar calculated with `reja_fakt.percentage`. |
| **MIJOZLAR** | `mijozlar_count` | Number badge (e.g., `2`, `1`). |

## 💻 TypeScript Interfaces for Frontend Codebases

Feel free to copy these type definitions directly into your frontend model/types file:

```typescript
export interface EmployeeTushum {
  amount: number;
  currency: string;
  formatted: string;
}

export type KPIStatusCode = 'COMPLETED' | 'IN_PROGRESS';

export interface EmployeeRejaFakt {
  plan_target: number;
  fact_amount: number;
  percentage: number;
  currency: string;
  status: 'Bajarildi' | 'Jarayonda' | string;
  status_code: KPIStatusCode;
  formatted_plan: string;
  formatted_fact: string;
}

export interface EmployeeListItem {
  id: string;
  first_name: string;
  last_name: string;
  phone: string;
  secondary_phone?: string | null;
  address?: string | null;
  department_id: string;
  department_name?: string;
  department_display_name?: string;
  fixed_salary: number;
  currency: string;
  color?: string;
  picture_url?: string | null;
  is_active: boolean;
  user_id?: string;
  username?: string;
  user_role: string;
  user_status: string;
  
  // New Calculated Metrics
  tushum: EmployeeTushum;
  reja_fakt: EmployeeRejaFakt;
  mijozlar_count: number;
}
```
